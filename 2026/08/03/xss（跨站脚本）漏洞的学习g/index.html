前言

跨站脚本（Cross-Site Scripting，XSS）
XSS是一种发生在前端浏览器端的漏洞，所以其危害的对象也是前端用户。
其目的一般都是为了攻击用户，拿到用户的Cookies等信息。

2.存储型XSS

可以直接在留言板里面写入
你输入一次他就会一直留下来
你每次打开这个网页他都会给你弹窗
顾名思义 存储型
存储型 XSS 的数据最终保存在服务器端的数据库（Database）中
持久性： 因为存储在数据库里，这些数据不会因为你关闭浏览器或重启电脑而消失

3.DOM型XSS

DOM（Document Object Model，文档对象模型） 是浏览器将 HTML 文档解析后，在内存中树立起来的一棵 “节点树”。

  • 文档节点： 整个网页的根节点（document）。
  • 元素节点： HTML 标签（如 <div>、<a>、<input>）。
  • 属性节点： 标签内的属性（如 href、class、src）。
  • 文本节点： 标签内部包含的文字。

    而DOM型xss其本质是前端开发中对不可信数据缺乏安全处理所导致的逻辑缺陷
    攻击完全发生在客户端，不与服务器交互
    通过javascript操作DOM元素实现攻击

    第一步实现了存储在dom（id）
    第二步实现了链接的执行
    第三步实现了弹窗

4.xss盲打

XSS 盲打（Blind XSS） 是存储型 XSS 的一种特殊形式。
它的核心特点是：攻击者在提交恶意代码时，前端页面不会有任何回显或弹窗；攻击只有在后台管理员登录后台查看数据时，才会真正触发。
