iOS-字段名英文拆词法

iOS 数据库字段名英文拆词法

用途：用英文语义判断”这个表/这个字段是干什么的”，从而在陌生数据库里找对答案所在，而不是靠全库搜索碰运气。
依据：第十一届美亚杯个人赛 Photos.sqlite 实战整理（2026-09-16）

一、先认前缀：Z

片段 含义
Z Core Data 强制前缀。Objective-C 的 Core Data 框架生成 SQLite 时，**所有表名、所有列名一律加 Z**。

看到 Z 开头，就知道这是苹果系（iOS/macOS）的库。
这是最快的识别标志——一眼判断出检材来自苹果生态，而不是安卓的普通 SQLite。

补充：Core Data 里 Z_PK 是主键，Z_ENT 是实体类型，Z_OPT 是乐观锁版本号。看到这三个就知道是 Core Data 标准结构。

二、表名拆解实战：ZADDITIONALASSETATTRIBUTES

片段 含义
Z Core Data 前缀（见上）
ADDITIONAL 附加的、补充的
ASSET 资产 —— 苹果 Photos 框架术语：相册里的一张照片 / 一个视频 = 一个 asset
ATTRIBUTES 属性

→ 「资产的附加属性表」

关键点在 ADDITIONAL + ATTRIBUTES：它不是独立实体，而是 ZASSET 的属性扩展。
一张照片在 ZASSET 有一行，在这张表恰好也一行（靠 Z_PK 关联）。

这一点决定了它能用来计数。

三、字段名拆解实战：ZIMPORTEDBYDISPLAYNAME

片段 含义
Z Core Data 前缀
IMPORTED 被导入（import 的过去分词）
BY 由……
DISPLAY NAME 显示名称 —— 用户看得懂的名字（”Safari”），区别于机器用的 bundle id

→ 「由哪个 App 的显示名导入的」

语义链条（第 41 题的关键）

题目的”下载”，在系统里落成的动作是”导入”。
盯着 download 找不到，正确的动词是 imported。

四、通用词汇表（可迁移，背下来）

表性质判断

看到 判断 能否计数
表尾 ATTRIBUTES / PROPERTIES / INFO 属性扩展表，与主表一对一 ✅ 可
含 CLOUD 云端副本，与本地重复 ❌ 会重复
含 TRANSACTION / LOG / HISTORY / JOURNAL / EVENT 日志表，一行 = 一次事件 ❌ 行数膨胀
含 TEMP / CACHE 临时/缓存 ❌ 不稳定
含 DELETED / TRASH / TOMBSTONE 已删除记录 ⚠️ 视题目而定
含 MASTER 主表 ✅ 可

字段性质判断

看到 含义
尾 DISPLAYNAME / TITLE / NAME 给人看的名字（”Safari”、”微信”）
尾 IDENTIFIER / UUID / HASH / ID 给机器看的 ID（com.apple.mobilesafari）
含 IMPORTED BY / SOURCE / ORIGIN 来源（哪个 App / 哪来的）
含 ORIGINAL 修改前 / 导入前的原始值
含 DATE / TIME / TIMESTAMP 时间戳（注意单位：秒还是毫秒）
含 COUNT / NUMBER 计数字段
以 IS / HAS 开头（如 ZHASADJUSTMENTS、ZTRASHEDSTATE） 布尔标志位（1=是，0=否）
含 BUNDLEID 产生这个记录的应用包名

五、判据：遇到”数一数有多少个 X”的题，怎么办

按顺序自问：

  1. X 是”实体”还是”事件”？
    • 实体（照片、消息、联系人）→ 去主表/属性表数
    • 事件（操作、变更、访问）→ 那是日志，别拿它当实体数
  2. 这张表与主表是一对一还是一对多？
    • 一对一（属性表）→ 行数 = 实体数 ✅
    • 一对多（日志表）→ 一个实体可能有多行 ❌
  3. 有没有云端副本？
    • 有 CLOUD 字样的表可能是同一批数据的第二份，别和本地相加
  4. 要不要过滤类型？
    • 数”图片”要排除视频（ZKIND = 0）->这部分在前面的美亚杯一题中提到
    • 数”未删除”要排除回收站（ZTRASHEDSTATE = 0）

六、完整例子回顾：第 41 题

题目：通过 Safari 下载了多少个图片文件？（答案 2）

表.列 英文拆解 判定
ZADDITIONALASSETATTRIBUTES.ZIMPORTEDBYDISPLAYNAME 资产属性表 · 由谁导入的显示名 ✅ 正解
ZADDITIONALASSETATTRIBUTES.ZIMPORTEDBYBUNDLEIDENTIFIER 同上，但用包名 同一事实的另一种写法
ZCLOUDMASTER.ZIMPORTEDBYDISPLAYNAME 云端主表 ⚠️ 云端副本，会重复
ATRANSACTIONSTRING.ZNAME 变更事务表 ❌ 日志，一行 = 一次事件

全库搜 Safari 各自都命中 2，简单相加 = 6，正确答案 = 2。

PS：这部分还有待学习(DOGE)

七、一句话总结

表名告诉你”这是什么东西的集合”，字段名告诉你”这个属性是什么意思”。

看懂英文，就知道该数哪一列——这比全库搜索靠谱得多。
